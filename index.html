About

I'm a Master's student at EPITA on the GISTRE track (low-level & systems engineering). I work on compilers, systems software, and the developer tools that sit close to the machine.

I was selected for Google Summer of Code 2026 with Debian (one of the 1,141 contributors accepted worldwide, out of 15,245 applicants) to build debian-lsp, a Language Server Protocol implementation for Debian packaging files.

I contribute to several open-source projects: gccrs (the GCC Rust front-end) at Embecosm, Swift, and Debian. To work on Swift from NixOS, which upstream doesn't support, I wrote swift-nixos: a single Nix flake that builds the full Swift 6.5 toolchain (compiler, standard library, C++ interop, and Foundation) from source out of a clean dev shell. I'm now working with nixpkgs maintainers to bring Swift 6.x to nixpkgs itself.

Alongside that I maintain EPITA's Tiger Compiler, where I write SSA-based optimization passes, and build my own systems software: a POSIX shell, Lux (a terminal editor inspired by Helix), and Mole (a keyboard-driven X11 navigator).

Open to a 6-month internship from February 2027 in compilers, language tooling, or low-level systems.

swift-nixos

A reproducible flake.nix that builds the full Swift 6.5 toolchain from source on NixOS, which upstream doesn't support. Reverse-engineered the build to solve a deep cascade of toolchain problems: DT_RUNPATH vs transitive rpath, glibc sysroot detection, a complete bootstrap runtime, and ncurses shimming.

  • Nix / flake.nix
  • Swift
  • LLVM
  • Toolchain
  • Linux

Lux

A modal, Helix-inspired terminal editor written from scratch in Rust: a rope text buffer, incremental tree-sitter highlighting, an undo tree and a hand-written LSP client. A deep dive into how editors really work.

  • Rust

// Systems ↗

Mole

Mole (short for Mouseless) is a keyboard-driven mouse navigator for X11. It labels every word on screen with a hint; type one and the pointer teleports there. Reads the screen with OCR, draws the overlay and moves the pointer via x11rb, all from a daemon.

  • Rust
  • X11 / x11rb
  • OCR
  • Daemon
