About

I'm a Master's student at EPITA on the GISTRE track — low-level & systems engineering. I work on compilers, systems software, and the developer tools that sit close to the machine.

I was selected for Google Summer of Code 2026 with Debian — accepted among 15,245 applicants worldwide (a 7.5% acceptance rate) — to build debian-lsp, a Language Server Protocol implementation for Debian packaging files.

I contribute to several open-source projects — among them the Swift compiler, gccrs (the GCC Rust front-end) at Embecosm, and Debian. Alongside that I maintain EPITA's Tiger Compiler, where I write SSA-based optimization passes. I also build my own systems software — a POSIX shell, a Helix-inspired editor, and a keyboard-driven X11 navigator.

// Toolchain ↗

swift-nixos

A reproducible flake.nix that builds the full Swift 6.5 toolchain from source on NixOS — which upstream doesn't support. Reverse-engineered the build to solve a deep cascade of toolchain problems: DT_RUNPATH vs transitive rpath, glibc sysroot detection, a complete bootstrap runtime, and ncurses shimming.

  • Nix / flake.nix
  • Swift
  • LLVM
  • Toolchain
  • Linux

A modal, Helix-inspired text editor written from scratch in Rust — selection-first editing, multiple cursors and a tree-sitter-driven rendering pipeline. A deep dive into terminal UIs, text buffers and editor internals.

// Systems ↗

Mole

Mole — short for Mouseless — is a keyboard-driven mouse navigator for X11. It hops the pointer around the screen like a mole, using a Vimium-style hint mode over the AT-SPI accessibility tree (with OCR fallback) and x11rb. Built for i3.

  • Rust
  • X11 / x11rb
  • AT-SPI
  • i3wm
