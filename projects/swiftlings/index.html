Overview

Rustlings is how a lot of people first get their hands dirty with Rust: a series of tiny broken programs you fix one by one, with a watcher that recompiles as you go. There was no good equivalent for learning Swift on Linux, where most tooling still assumes a Mac and Xcode. swiftlings-linux is that: 100+ small exercises across the language, run entirely on the open-source Swift toolchain from swift.org.

The install story is deliberately boring: install Swift 6.x, git clone, make install, then swiftlings. No Mac, no Xcode, no platform-specific anything.

What I built

  • A SwiftPM command-line tool (ArgumentParser + Rainbow): swiftlings list / run / hint / watch / reset, replacing the old script-based runner with a real Linux-first CLI.
  • A Rustlings-style watch mode: output and errors at the top, a colored progress bar, the current exercise path and a key menu (n:next / h:hint / l:list / c:check all / x:reset / q:quit) pinned to the bottom; it recompiles the moment you save.
  • 100+ exercises across the language, each linked to the matching chapter of The Swift Programming Language so a hint always points at the canonical docs.
  • Honest Linux portability: fixed the exercises that relied on Apple-only behaviour, moved to Swift 6 language mode (strict concurrency: a single-threaded non-blocking watch loop, nonisolated(unsafe) where needed), and wired up CI on the official swift:6.1 container so every push builds and tests.

For the Swift community

The whole thing is written for the Swift Forums as a Linux-first on-ramp, crediting the upstream Rustlings and Swiftlings projects it builds on. It is MIT-licensed and the CI keeps it honest: if an exercise stops compiling on a clean Swift 6.1 Linux image, the build goes red.
