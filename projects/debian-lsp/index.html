Overview

Debian packaging is driven by a family of metadata files — debian/control, debian/changelog, debian/rules and more. debian-lsp brings modern editor intelligence to these files through the Language Server Protocol, so any LSP-capable editor (VS Code, Neovim, Helix…) gets first-class support for editing Debian packages.

It was selected as a Google Summer of Code 2026 project under the Debian organization — accepted among 15,245 applicants worldwide.

What it provides

  • Completions across packaging fields and values
  • Diagnostics for malformed or invalid metadata
  • Hover documentation and go-to-definition
  • Formatting and code actions
  • Inlay hints and semantic highlighting
