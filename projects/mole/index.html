Overview

Mole is keyboard-only mouse navigation for Linux/X11. Press a key and Mole labels every word on your screen with a short hint; type the label and the pointer teleports there — then click, drag, or keep moving by keyboard. The name fits twice over: mouse-less, and a mole tunnels straight to wherever you point.

Demo

How it works

The hard part isn't the idea — it's the systems plumbing. Mole is a daemon built as a pipeline so a trigger only does the per-interaction work:

  • The map is text. Mole reads the screen with OCR rather than the accessibility tree — so document text, terminals, Electron apps and custom-drawn UIs are all hintable, not just declared widgets. (An earlier AT-SPI design was abandoned for exactly this reason.)
  • Vimium-style hints — two-letter labels are drawn over every word; type one and the pointer teleports there.
  • A borderless, transparent X11 overlay the window manager won't touch, drawn and controlled via x11rb.
  • Synthetic input the rest of the system believes is hardware, for move / click / drag.
  • Plain hjkl movement that does no scanning at all, so it feels instant.

Every stage — capture → detect → label → render → match → act — lives in its own module. The full design story is in the build journey.
