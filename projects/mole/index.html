Overview

Mole is short for Mouseless — it lets you drive the pointer entirely from the keyboard. The name fits the behaviour: the cursor pops up all over the screen like a mole, jumping straight to whatever you want to click.

How it works

  • Vimium-style hint mode — overlays labels you type to jump the pointer
  • Traverses the AT-SPI accessibility tree to find targets
  • OCR fallback when the accessibility tree is incomplete
  • Screen capture and pointer control via x11rb
  • Built for the i3 window manager on X11
