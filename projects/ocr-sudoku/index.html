Overview

This project takes a photograph of a Sudoku grid and returns the solved puzzle — written entirely in C, with the image pipeline, the digit-recognition neural network, and the solver all built from scratch.

The pipeline

  • Image preprocessing — grayscale, binarization, rotation/deskew
  • Grid detection and cell segmentation
  • Neural network for digit recognition
  • Constraint-propagation solver for the puzzle
  • Render of the completed grid
