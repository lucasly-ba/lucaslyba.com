Overview

The Tiger Compiler is the flagship project of EPITA's compiler course: a complete compiler for the Tiger language, built in modern C++ to teach compiler construction and software-design patterns. Before anything else, I built the whole thing myself as a student (lexer, parser, binding, type-checking, escape analysis, IR translation and a back-end), following the full assignment chain front-end to back-end.

I was then accepted into the assistant team as a Tiger maintainer working on SSA. SSA optimization has been handed down through generations of maintainers: I am the 7th maintainer of the 7th generation to take it on, and the one who brought it across the finish line, landing it in the main project after years of iteration.

I built on the merged student work handed down from Elsa Keirouz, with Julie Fiadino helping me throughout.

The optimizer was written the hard way: reading the algorithms in Andrew W. Appel's Modern Compiler Implementation in ML, working through them, and implementing them by hand.

Five SSA optimization passes

Each pass runs on the Low-Level IR (LIR) after conversion to SSA form. For each one below: a small Tiger program, its real LIR before the pass, and the same LIR after, captured by running tc directly.

01 Constant folding--constant-folding --ssa

Expressions over known constants (3 + 4, 10 * 2) are evaluated at compile time instead of at runtime.

/* 01-constant-folding.tig */

/* BEFORE: expressions computed at runtime */
let
  var a := 3 + 4
  var b := 10 * 2
  var c := a + b
in
  print_int(c);   /* expects 27 */
  print("\n")
end

/* AFTER: compiler evaluates at compile time
   var a := 7
   var b := 20
   var c := 27    <-- no addition at runtime */

02 Constant propagation--constant-propagation --ssa

A variable known to hold a constant is substituted directly at its uses, so the value is never reloaded from memory.

/* 02-constant-propagation.tig */

/* BEFORE: compiler reloads `c` from memory on every use */
let
  var c := 27
  var d := c * 3
  var e := c + 1
in
  print_int(d);   /* expects 81 */
  print("\n");
  print_int(e);   /* expects 28 */
  print("\n")
end

/* AFTER: compiler substitutes the known value directly
   var d := 27 * 3   →   81
   var e := 27 + 1   →   28   <-- no memory load */

03 Copy propagation--copy-propagation --ssa

When one variable is just a copy of another (e := d), every use of the copy is replaced by the original and the copy is eliminated.

/* 03-copy-propagation.tig */

/* BEFORE: `e` is just an alias for `d`, loaded separately */
let
  var d := 81
  var e := d          /* copy */
  var f := e + 1
in
  print_int(f);   /* expects 82 */
  print("\n")
end

/* AFTER: compiler replaces every use of `e` with `d`
   var f := d + 1     <-- `e` is eliminated entirely */

04 Dead-code elimination--dead-code-elimination --ssa

An assignment whose result is never read (unused := 999) is removed entirely: no computation, no memory write.

/* 04-dead-code-elimination.tig */

/* BEFORE: `unused` is assigned but never read */
let
  var result := 42
  var unused := 999   /* assigned, never read */
in
  print_int(result);  /* expects 42 */
  print("\n")
end

/* AFTER: DCE removes the assignment entirely
   var unused := 999  <-- gone, no computation, no memory write */

05 Unreachable-code elimination--constant-conditions --ssa

A branch with a constant condition (if 1 = 1) is resolved at compile time and the dead branch is dropped.

/* 05-unreachable-code.tig */

/* BEFORE: condition is always true, else branch never runs */
let
  var result :=
    if 1 = 1 then     /* always true */
      42
    else
      0               /* unreachable */
in
  print_int(result);  /* expects 42 */
  print("\n")
end

/* AFTER: compiler eliminates the else branch
   var result := 42   <-- condition and else are gone */

The same passes, as control-flow graphs

The listings above show each pass on a straight-line program. To see them act on real control flow, here each optimization runs on a small program with a branch, and tc dumps the basic-block flow graph with --bbflowgraph-dump. Each box is a basic block of LIR; the arrows are the control-flow edges. Orange is before the pass, green is after.

01 Constant folding--constant-folding

The two branch blocks each fold a constant expression: 3 + 4 and 10 * 2 become 7 and 20 in place, before the program ever runs.

let var x := 0 in
  if x = 0 then x := 3 + 4 else x := 10 * 2;
  print_int(x); print("\n")
end

02 Constant propagation--constant-propagation

c is known to be 27, so every use of it in the branch blocks is replaced by the literal and the load disappears.

let var c := 27 var x := 0 in
  if c > 0 then x := c * 3 else x := c + 1;
  print_int(x); print("\n")
end

03 Copy propagation--copy-propagation

e is just a copy of d. Every use of e (temp t1.1) in the branches is rewritten to d (temp t0.1), and the copy is dropped.

let var d := 81 var e := d var x := 0 in
  if e > 0 then x := e + 1 else x := e - 1;
  print_int(x); print("\n")
end

04 Dead-code elimination--dead-code-elimination

unused is written in both branches (999 / 123) and never read. Its stores, and the phi that joined them, are deleted; the graph keeps its shape but the blocks shrink.

let var result := 0 var unused := 0 in
  if result = 0 then (result := 42; unused := 999)
  else (result := 7; unused := 123);
  print_int(result); print("\n")
end

05 Unreachable-code elimination--constant-conditions

The condition 1 = 1 is always true. The cjump collapses to an unconditional jump and the dead else block is dropped entirely: four blocks become three.

let var x := 0 in
  if 1 = 1 then x := 42 else x := 0;
  print_int(x); print("\n")
end

All passes at once

Chained together (--ssa-optimize), what looks like six variables and a branch collapses to a single constant: the compiler ends up emitting print_int(82).

/* 06-all-passes.tig: all optimization passes chained */

/* The compiler runs all passes in sequence.
   What looks like 6 variables and a branch
   collapses to a single constant: 82           */

let
  var a      := 3 + 4        /* constant folding      → 7  */
  var b      := 10 * 2       /* constant folding      → 20 */
  var c      := a + b        /* constant folding      → 27 */
  var d      := c * 3        /* constant propagation  → 81 */
  var e      := d            /* copy propagation      → eliminated */
  var f      := e + 1        /* copy propagation      → 82 */
  var unused := 999          /* dead code elimination → eliminated */
  var result := f
  var branch :=
    if 1 = 1 then            /* unreachable code elim → else gone */
      result
    else
      0
in
  print_int(branch);         /* compiler sees: print_int(82) */
  print("\n")
end

/* With all passes applied, the entire program reduces to:
   print_int(82)
   print("\n")               */
