Overview

The Tiger Compiler is EPITA's flagship compiler project — a full compiler for the Tiger language, written from scratch in modern C++. I built it through every phase of the pipeline, then became one of six maintainers responsible for the project used by every third-year cohort.

The pipeline, front to back

  • Front-end — lexing, parsing, AST construction
  • Semantic analysis — name binding, scoping, type-checking
  • Translation — lowering to intermediate representation
  • Back-end — instruction selection, register allocation, code generation

SSA-based optimization back-end

On the back-end I implemented a suite of SSA-based optimization passes:

  • Constant propagation
  • Constant folding
  • Copy propagation
  • Dead code elimination
  • Unreachable block removal
