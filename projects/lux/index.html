Overview

Lux is a terminal text editor built in Rust, inspired by Helix's selection-first, modal editing model. It's a from-scratch exploration of how a real editor works under the hood — text storage, modal input, and syntax-aware rendering.

What I built

  • Selection-first modal editing — actions operate on selections
  • Multiple cursors for parallel edits
  • tree-sitter integration for syntax-aware highlighting
  • An efficient text buffer and rendering pipeline for the terminal
