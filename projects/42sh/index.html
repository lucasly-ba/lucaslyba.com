Overview

42sh is a full Unix shell implemented in C, following the POSIX specification. It runs scripts and interactive sessions, parsing the shell grammar into an AST and executing it with proper process and signal semantics.

What I built

  • Lexer & parser for the POSIX shell grammar
  • AST execution engine
  • Built-ins, variables and expansions
  • Redirections and pipelines
  • Job control and signal handling
